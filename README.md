## README

Simple [Obsidian](https://obsidian.md/) vault template.

Feel free to use additional custom css from [obsidian.snippets](https://github.com/orca131/obsidian.snippets) repo.

## Hotkeys

| Key binding | Command                     |
| ----------- | --------------------------- |
| `Alt+A`     | Add alias                   |
| `Alt+L`     | Insert internal link        |
| `Alt+T`     | Add tag                     |
| `Alt+X`     | Cycle bullet/checkbox       |
| `Alt+J`     | Open today's daily note     |
| `Alt+C`     | Insert code block           |
| `Alt+V`     | Manage vaults               |
| `Alt+F`     | Move file to another folder |
| `Alt+↓`     | Move line down              |
| `Alt+↑`     | Move line down up           |
| `Alt+←`     | Navigate back               |
| `Alt+→`     | Navigate forward            |
| `Alt+S`     | Open settings               |
| `Alt+P`     | Toggle fold properties      |
| `Alt+Q`     | Toggle blockquote           |
| `Alt+E`     | Toggle left sidebar         |
| `Ctrl+R`    | Toggle source mode          |
| `Alt+R`     | Toggle right sidebar        |
